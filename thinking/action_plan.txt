=== ПРИОРИТЕТ 1: КРИТИЧЕСКИЕ ПРОБЛЕМЫ ===

1. ОШИБКА DOCKER COMPOSE
   Проблема: Проект не запускается через docker compose
   Причина: Отсутствует uv.lock файл, необходимый для 'uv sync --frozen'
   Решение:
   - Создать uv.lock командой: uv lock
   - Добавить uv.lock в репозиторий
   - Или изменить Dockerfile: убрать --frozen флаг
   - Проверить монтирование init.sql (права доступа, путь)

2. ДУБЛИРОВАНИЕ ЗАВИСИМОСТЕЙ
   Проблема: Два файла зависимостей (pyproject.toml и requirements.txt)
   Решение:
   - Удалить requirements.txt
   - Использовать только uv с pyproject.toml
   - Обновить README (убрать упоминание requirements.txt)

=== ПРИОРИТЕТ 2: АРХИТЕКТУРНЫЕ УЛУЧШЕНИЯ ===

3. СИСТЕМА МИГРАЦИЙ

   Решение:

   - Инициализировать: alembic init migrations
   - Создать начальную миграцию на основе init.sql
   - Настроить автоматическое применение при запуске
   - Обновить docker-compose.yml для использования Alembic

4. ЛИНТИНГ И ФОРМАТИРОВАНИЕ
   Проблема: Отсутствуют линтеры и форматеры кода
   Решение:

     [tool.black]
     [tool.isort]
     [tool.mypy]
     [tool.flake8]
   - Настроить pre-commit хуки
   - Добавить GitHub Actions workflow

=== ШАГИ ЗАПУСКА ===

1. Создать uv.lock:
   ```bash
   uv lock
   ```

2. Удалить requirements.txt

3. Установить Alembic и создать миграции:
   ```bash
   uv add alembic
   alembic init migrations_alembic
   # Создать начальную миграцию на основе init.sql
   ```

4. Обновить Dockerfile:
   - Убрать --frozen или убедиться что uv.lock существует
   - Добавить шаг применения миграций

5. Добавить линтеры:
   ```bash
   uv add --dev black isort mypy flake8
   ```

6. Обновить docker-compose.yml:
   - Добавить volume для Alembic миграций
   - Настроить выполнение миграций перед запуском приложения

7. Протестировать запуск:
   ```bash
   docker compose down -v
   docker compose up --build
   ```

8. Запустить тесты:
   ```bash
   docker compose exec app pytest -v
   ```
