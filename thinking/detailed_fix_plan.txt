=== 2. DOCKER COMPOSE НЕ ЗАПУСКАЕТСЯ ===

ТЕКУЩАЯ СИТУАЦИЯ:
- Dockerfile использует 'uv sync --frozen --no-dev'
- Файл uv.lock отсутствует в репозитории
- Без uv.lock команда 'uv sync --frozen' падает с ошибкой

КОНКРЕТНЫЕ ДЕЙСТВИЯ:

ШАГ 1: Создать uv.lock файл
```bash
# Убедиться, что uv установлен глобально
curl -Ls https://astral.sh/uv/install.sh | sh

# В корне проекта создать lock файл
uv lock
```

ШАГ 2: Добавить uv.lock в репозиторий
```bash
git add uv.lock
git commit -m "Add uv.lock for reproducible builds"
```

АЛЬТЕРНАТИВНОЕ РЕШЕНИЕ (если не хотим добавлять uv.lock):
Изменить Dockerfile, строка 12:
Было: RUN uv sync --frozen --no-dev
Стало: RUN uv sync --no-dev

ШАГ 3: Проверить монтирование init.sql
Убедиться, что в docker-compose.yml правильно указан путь:
```yaml
volumes:
  - ./migrations/init.sql:/docker-entrypoint-initdb.d/init.sql:ro
```

ШАГ 4: Тестирование запуска
```bash
# Очистить предыдущие контейнеры и volumes
docker compose down -v

# Собрать и запустить
docker compose up --build
```

=== 4. МИГРАЦИИ ЛУЧШЕ ДЕЛАТЬ СТАНДАРТНЫМИ ИНСТРУМЕНТАМИ ===

ТЕКУЩАЯ СИТУАЦИЯ:
- Используется простой SQL-скрипт migrations/init.sql
- Нет версионирования, истории, возможности отката

КОНКРЕТНЫЕ ДЕЙСТВИЯ:

ШАГ 1: Установить Alembic
```bash
uv add alembic
```

ШАГ 2: Инициализировать Alembic
```bash
uv run alembic init migrations_alembic
```

ШАГ 3: Настроить alembic.ini
- Указать правильный URL базы данных:
```ini
sqlalchemy.url = postgresql://user:pass@localhost/grades_db
```
- Или оставить динамическое чтение из переменных окружения (рекомендуется)

ШАГ 4: Настроить env.py для использования asyncpg и pydantic-settings
Нужно модифицировать migrations_alembic/env.py:
```python
import os
from logging.config import fileConfig
from app.config import settings
from sqlalchemy import engine_from_config, pool
from alembic import context

# this is the Alembic Config object
config = context.config

# Interpret the config file for Python logging
fileConfig(config.config_file_name)

# Переопределяем sqlalchemy.url из настроек приложения
config.set_main_option("sqlalchemy.url", settings.database_url)

# ... остальной код ...
```

ШАГ 5: Создать начальную миграцию
```bash
uv run alembic revision -m "initial" --autogenerate
```

ШАГ 6: Создать скрипт для автоматического применения миграций при запуске
Например, добавить в app/database.py:
```python
from alembic import command
from alembic.config import Config

async def run_migrations():
    alembic_cfg = Config("alembic.ini")
    alembic_cfg.set_main_option("sqlalchemy.url", settings.database_url)
    command.upgrade(alembic_cfg, "head")
```

И вызвать в lifespan перед созданием пула соединений.

ШАГ 7: Обновить docker-compose.yml
Добавить выполнение миграций при запуске приложения:
```yaml
app:
  build: .
  command: >
    sh -c "uv run alembic upgrade head &&
           uvicorn app.main:app --host 0.0.0.0 --port 8000"
```

=== 9. ДОПОЛНИТЕЛЬНЫЕ УЛУЧШЕНИЯ ===

9.1 Добавить линтеры и форматеры
```bash
uv add --dev black isort flake8 mypy
```

Создать pyproject.toml конфигурацию:
```toml
[tool.black]
line-length = 88
include = '\.py$'

[tool.isort]
profile = "black"

[tool.flake8]
max-line-length = 88
extend-ignore = "E203,W503"

[tool.mypy]
python_version = "3.12"
warn_return_any = true
warn_unused_configs = true
disallow_untyped_defs = true
```

9.2 Добавить pre-commit хуки
Создать .pre-commit-config.yaml:
```yaml
repos:
  - repo: https://github.com/psf/black
    rev: 23.12.1
    hooks:
      - id: black
  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort
  - repo: https://github.com/pycqa/flake8
    rev: 7.0.0
    hooks:
      - id: flake8
```

9.3 Настроить GitHub Actions
Создать .github/workflows/ci.yml:
```yaml
name: CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: postgres
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
        ports:
          - 5432:5432
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v3
      - run: uv sync --dev
      - run: uv run pytest -v
```
