ШАГ 3: ДОБАВИТЬ ОГРАНИЧЕНИЯ БЕЗОПАСНОСТИ
В app/config.py добавить:
```python
class Settings(BaseSettings):
    database_url: str
    max_upload_size_mb: int = 10  # 10 MB максимум
    # ...
```

В app/routers/upload.py добавить проверку размера:
```python
MAX_FILE_SIZE = settings.max_upload_size_mb * 1024 * 1024

@router.post("/upload-grades")
async def upload_grades(file: UploadFile) -> UploadResponse:
    # Проверить размер файла
    file.file.seek(0, 2)  # Перейти в конец файла
    size = file.file.tell()
    file.file.seek(0)  # Вернуться в начало
    if size > MAX_FILE_SIZE:
        raise HTTPException(413, f"File too large. Max size: {settings.max_upload_size_mb}MB")
    # ...
```

        raise HTTPException(503, detail=f"Database unavailable: {str(e)}")
